# Adversarial report for 0.0.8

Pass run on the `cursor/stable-0-0-8-143b` branch before the 0.0.8 release. The
suite is `cargo test --locked`. Findings below are the ones fixed in this
series or left documented. Earlier fixed items remain in
[v0.0.2.md](v0.0.2.md).

## Fixed

| Id | Severity | What was wrong | Fix | Test |
| -- | -------- | -------------- | --- | ---- |
| H1 | High | `git show` and diff paths could run a repository `textconv` or external diff driver. | `--no-textconv` and `--no-ext-diff` on every show and patch path. | `adversarial_readonly_git`, `log` unit tests |
| D5 | High | Corrupt `settings.json` on disk was replaced when the app saved defaults after a failed load. | `loaded_ok` blocks `save_to` until a successful load or a missing file. | `adversarial_corrupt_settings_are_not_overwritten`, `settings_load_tests` |
| D6 | Medium | A non-string `ui_font` or `terminal_font` rejected the whole file. | `lenient_font` ignores bad types. | `adversarial_settings`, `settings` unit tests |
| E2 | Critical | Invalid PTY resize (0 cells, NaN scale) made alacritty call `process::exit`. | Clamp pixels, skip resize when the child is gone or size unchanged. | `terminal` unit tests |
| E3 | High | OSC 52 and bracketed-paste breakout from the embedded shell. | `Osc52::Disabled`; paste bytes strip `ESC [201~` when bracketed. | `terminal` unit tests |
| E4 | Medium | Dock launch with unset `LANG`/`LC_*` left the shell without UTF-8. | `shell_env_from` sets `LANG` and `LC_CTYPE` to `en_US.UTF-8` when all locale vars are blank. | `terminal` unit tests |
| C6 | High | macOS GUI discovery probed `/usr/bin/git` before Homebrew and often hung in the xcrun shim. | Ordered fallbacks; shim last and only when CLT or Xcode git exists. | `macos_git_discovery`, `adversarial_discover` |
| B3 | Medium | Git 2.56's broken-gitfile fatal was not classified as `NotARepository`. | Match `fatal: gitfile does not point to a valid repository`. | `exec` unit test, `adversarial_repo_states` |
| H2 | High | A planted symlink on the avatar temp path could write outside the cache. | Unlink temp path, `create_new`; reject symlink metadata. | `avatars` unit tests |
| H3 | High | A keychain save that finished after the UI deadline could still publish. | Generation cancel, `still_current`, `revert_save` on late success. | `token` unit tests |
| F8 | Medium | macOS CI flaky test timing. | Temporary triple `cargo test` loop on macOS (reverted after green run). | CI job `cargo test (macos-26)` |

## Checked and already safe

Unix git and terminal children still drop inherited `GIT_*` except the SSH helpers, and drop `GH_TOKEN` / `GITHUB_TOKEN`. Repository `git show` and log paths keep `--no-replace-objects` and the 0.0.2 git hardening. `actionlint` and `zizmor` stay in CI. Cross-target `cargo check` for Intel macOS runs on `macos-26` after tests.
