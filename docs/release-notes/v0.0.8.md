Cthulhu Git 0.0.8 ships bundled interface and terminal fonts, hardens settings and the embedded shell, and steadies macOS Git discovery and CI. There is still no commit, push, stage or diff.

**Download Cthulhu Git:** [Mac (Apple Silicon and Intel)](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.8/cthulhu-git-v0.0.8-macos-universal.dmg) · [Windows](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.8/cthulhu-git-v0.0.8-x86_64-pc-windows-msvc.zip) · Linux: [AppImage](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.8/cthulhu-git-v0.0.8-x86_64.AppImage), [.deb](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.8/cthulhu-git-v0.0.8-x86_64.deb), [.rpm](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.8/cthulhu-git-v0.0.8-x86_64.rpm), [.tar.gz](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.8/cthulhu-git-v0.0.8-x86_64-unknown-linux-gnu.tar.gz)

Git 2.15 or newer must already be installed; Cthulhu Git never bundles it. SHA-256 checksums are in `checksums.txt`.

The Linux packages need glibc 2.39 or newer: Ubuntu 24.04, Debian 13, Fedora 40 or later.

- **AppImage**, to try it without installing: `chmod +x cthulhu-git-v0.0.8-x86_64.AppImage`, then run it.
- **Debian and Ubuntu:** `sudo apt install ./cthulhu-git-v0.0.8-x86_64.deb`
- **Fedora:** `sudo dnf install ./cthulhu-git-v0.0.8-x86_64.rpm` (openSUSE Tumbleweed: `sudo zypper install` with the same file)

The Mac app is not signed by Apple yet. The first time, open it from Finder, then go to **System Settings → Privacy & Security** and click **Open Anyway**. From a terminal, `xattr -dr com.apple.quarantine "/Applications/Cthulhu Git.app"` does the same.

## Added

- **Bundled interface and terminal fonts.** Settings → Appearance lists every face shipped with the app. The interface defaults to Ubuntu; the terminal defaults to Meslo LGS NF. Packages include the font license notices next to the binary. By @don-linux. (#11)

## Changed

- **A 0.0.7 settings file with `terminal_font: null` now opens Meslo LGS NF**, not egui's built-in monospace. Blank or unknown names still fall back the same way. By @don-linux. (#11)
- **Finder and Dock no longer try `/usr/bin/git` first on macOS.** Homebrew, `/usr/local`, and MacPorts are searched ahead of Apple's shim. `/usr/bin/git` is used only when Command Line Tools or Xcode already provides a real `git`. By @don-linux. (#19)

## Fixed

- **Hovering a commit and opening a file diff do not run repository hooks.** `git show` and the log paths pass `--no-textconv` and `--no-ext-diff`, so a `textconv` or external diff driver cannot run. By @don-linux. (#19)
- **A bad terminal resize no longer quits the process.** Zero or non-finite cell sizes are clamped, and resize is skipped after the shell exits. By @don-linux. (#19)
- **The shell cannot write the clipboard through OSC 52**, and pasted text cannot break out of bracketed paste. By @don-linux. (#19)
- **A Dock launch with no locale gets UTF-8** in the terminal environment so paths and names stay readable. By @don-linux. (#19)
- **A failed read of `settings.json` is not overwritten by the next save.** A non-string font field no longer discards the rest of the file. By @don-linux. (#19)
- **A Keychain prompt that outlives the deadline cannot save or delete the token afterward.** Late results are discarded and a save reverts what the prompt changed. By @don-linux. (#19)
- **The avatar cache does not follow a symlink at its temp path.** By @don-linux. (#19)
- **A `.git` gitfile that points nowhere is reported as "not a repository" on Git 2.56** as well as on older Git. By @don-linux. (#19)
