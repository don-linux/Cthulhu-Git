Cthulhu Git 0.0.2 is the first version of the design: a home view and a Git view. The Git view starts listing a Git directory — the repository you open — so the app can scale from a solid base. It is still read-only: no commit, push, stage or diff yet.

**Download Cthulhu Git:** [Mac (Apple Silicon and Intel)](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.2/cthulhu-git-v0.0.2-macos-universal.dmg) · [Windows](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.2/cthulhu-git-v0.0.2-x86_64-pc-windows-msvc.zip) · Linux: [AppImage](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.2/cthulhu-git-v0.0.2-x86_64.AppImage), [.deb](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.2/cthulhu-git-v0.0.2-x86_64.deb), [.rpm](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.2/cthulhu-git-v0.0.2-x86_64.rpm), [.tar.gz](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.2/cthulhu-git-v0.0.2-x86_64-unknown-linux-gnu.tar.gz)

Git 2.15 or newer must already be installed; Cthulhu Git never bundles it. SHA-256 checksums are in `checksums.txt`.

The Linux packages need glibc 2.39 or newer: Ubuntu 24.04, Debian 13, Fedora 40 or later.

- **AppImage**, to try it without installing: `chmod +x cthulhu-git-v0.0.2-x86_64.AppImage`, then run it.
- **Debian and Ubuntu:** `sudo apt install ./cthulhu-git-v0.0.2-x86_64.deb`
- **Fedora:** `sudo dnf install ./cthulhu-git-v0.0.2-x86_64.rpm` (openSUSE Tumbleweed: `sudo zypper install` with the same file)

The Mac app is not signed by Apple yet. The first time, open it from Finder, then go to **System Settings → Privacy & Security** and click **Open Anyway**. From a terminal, `xattr -dr com.apple.quarantine "/Applications/Cthulhu Git.app"` does the same.

## Added

- **Home view.** An **Open repository…** button opens the system folder dialog, and the ten most recent repositories stay one click away. Any folder inside a repository works; its root is what gets remembered.
- **Git view.** Shows the repository name, the current branch, the latest commit and a history that stays collapsed until you open it. A **Home** button goes back to pick another repository.
- **Starts listing a Git directory.** The history is the first listing of what is in the repository: up to 1000 commits, newest first, each as a 12-character hash and its summary. That listing is the step this version takes so the app can scale from here.
- **A solid base.** The last repository reopens on the next launch. Theme, last repository and recents are stored in a settings file, and colors come from one swappable dark theme so later screens share the same foundation. By @don-linux. (#2)
