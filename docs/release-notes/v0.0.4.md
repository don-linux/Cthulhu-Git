Cthulhu Git 0.0.4 is the repository view you work in: local branches on the left, the commit history in the middle, and the latest commit on the right, with a shell under that commit. Settings can change the font that shell uses. The Git views stay read-only.

**Download Cthulhu Git:** [Mac (Apple Silicon and Intel)](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.4/cthulhu-git-v0.0.4-macos-universal.dmg) · [Windows](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.4/cthulhu-git-v0.0.4-x86_64-pc-windows-msvc.zip) · Linux: [AppImage](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.4/cthulhu-git-v0.0.4-x86_64.AppImage), [.deb](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.4/cthulhu-git-v0.0.4-x86_64.deb), [.rpm](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.4/cthulhu-git-v0.0.4-x86_64.rpm), [.tar.gz](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.4/cthulhu-git-v0.0.4-x86_64-unknown-linux-gnu.tar.gz)

Git 2.15 or newer must already be installed; Cthulhu Git never bundles it. SHA-256 checksums are in `checksums.txt`.

The Linux packages need glibc 2.39 or newer: Ubuntu 24.04, Debian 13, Fedora 40 or later.

- **AppImage**, to try it without installing: `chmod +x cthulhu-git-v0.0.4-x86_64.AppImage`, then run it.
- **Debian and Ubuntu:** `sudo apt install ./cthulhu-git-v0.0.4-x86_64.deb`
- **Fedora:** `sudo dnf install ./cthulhu-git-v0.0.4-x86_64.rpm` (openSUSE Tumbleweed: `sudo zypper install` with the same file)

The Mac app is not signed by Apple yet. The first time, open it from Finder, then go to **System Settings → Privacy & Security** and click **Open Anyway**. From a terminal, `xattr -dr com.apple.quarantine "/Applications/Cthulhu Git.app"` does the same.

## Added

- **Local branches.** The left sidebar lists every local branch, with its name, commit count, and how it stands against its upstream: in sync, ahead, behind, or gone. The current branch is bold. Each row has a checkbox kept for a later history filter; the commit list still shows HEAD. Hide the sidebar with the panel button on the left of the top bar. That choice is remembered. By @don-linux.
- **Latest commit.** The right sidebar shows the newest commit: full hash, author, date, and message. Hide it with the panel button on the right of the top bar. That choice is remembered.
- **Integrated terminal.** A button at the right of the bottom bar opens a shell in the repository folder, under the latest commit. Opening it also opens the right sidebar. macOS and Linux start `SHELL`, or `/bin/sh` when that variable is empty; Windows starts PowerShell. You can type, select, copy, paste, and scroll, and drag the divider to resize it. It stays hidden until you open it, and that choice is remembered. Leaving the repository stops the shell. Its height is not saved.
- **Settings.** The gear on the bottom bar opens a settings window. The Terminal page picks the font family from the fonts installed on the machine, with a one-line preview that ignores the keyboard and pointer. Leave the name empty to keep the built-in monospace. The choice is saved immediately.

## Changed

- **The history is the center of the window.** It is still the latest 1000 commits, newest first, each as a 12-character hash and its summary. In 0.0.3 that list was the left sidebar and the latest commit filled the middle.
- **A hidden history sidebar now hides the branch list.** The saved preference keeps its previous name. If the history was hidden, the branch sidebar starts hidden and the history stays visible in the center.
