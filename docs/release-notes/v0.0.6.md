Cthulhu Git 0.0.6 keeps the 0.0.5 repository view and refactors it for quality and stability. Git, the embedded shell, and the picture requests were tightened so a hung command, a parent environment, or a planted program cannot rewrite what you see or leave processes behind. There is still no commit, push, stage or diff.

## Changed

- **Pull stays a fast-forward when Git is set to rebase.** Pull is `git pull --ff-only --no-rebase`. On Git 2.15 through 2.33, `--ff-only` alone still rebases when `pull.rebase` or `branch.<name>.rebase` is set. A divergence is still refused. By @don-linux. (#7)
- **The macOS terminal is a login shell.** It starts with `-l`, so `/etc/zprofile` and `~/.zprofile` run. Linux stays non-login, so an interactive bash still reads `~/.bashrc`. By @don-linux. (#7)
- **Git failures name what stopped.** A timeout, an output past the limit, a rejected command, and a non-zero exit are separate errors, and each names the command. A read error is a failure, not the end of the output. By @don-linux. (#7)

## Fixed

- **A timed-out Git command stops its helpers.** On Linux and macOS the command runs in its own process group. The time limit signals that group, then reaps descendants that called `setsid` and left it, so a helper cannot keep the pipe open. By @don-linux. (#7, #8)
- **Closing the terminal stops the session.** The shell is started and joined off the window thread. Closing it signals the session and reaps descendants that left it. A process id that was already reaped is not signaled. A folder the shell cannot enter is refused before anything starts. By @don-linux. (#7, #8)
- **macOS no longer launches the Xcode installer to find Git.** Homebrew and `/usr/local` are searched first. `/usr/bin/git` is the stub that opens the Command Line Tools installer and often never exits, so it is tried only when the Command Line Tools or Xcode git is already installed. By @don-linux. (#7)
- **Neighboring branches no longer share a graph color.** The checked-out branch keeps the first color. The next rows in the sidebar take the following colors, so two branches beside each other are not painted the same. By @don-linux. (#7)
- **A slow picture is not remembered as missing.** A timeout tries the next URL. A failed keychain delete still shows that a token is stored, and a keychain call that does not return is abandoned instead of freezing the window. Importing a token from GitHub CLI skips a file that is not executable and also looks in `~/.local/bin`. By @don-linux. (#7)

## Security

- **A parent process cannot point Git at another repository.** Every inherited `GIT_*` variable is removed, except `GIT_SSH`, `GIT_SSH_COMMAND`, `GIT_SSH_VARIANT`, and `GIT_ASKPASS`. That covers `GIT_EXEC_PATH` and `GIT_CONFIG_KEY_<n>`, so a hook cannot choose `core.sshCommand` or run a planted `git-remote-*`. `SSH_AUTH_SOCK`, `HOME`, and `PATH` stay. By @don-linux. (#7)
- **The terminal does not inherit Git redirects or tokens.** It unsets those same `GIT_*` variables, plus `GH_TOKEN` and `GITHUB_TOKEN`. A `SHELL` that is not an absolute path is ignored, so a repository cannot plant the program the terminal runs. By @don-linux. (#7, #8)
- **A token in a picture URL is left out of the error.** Requests stay on the known HTTPS hosts. A URL with credentials or a port is refused, and the message omits any user and password that were in it. The token is wiped from memory when it is dropped. By @don-linux. (#8)
