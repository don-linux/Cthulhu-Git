Cthulhu Git 0.0.7 adds a folder shortcut, local branch switching, and an About page. Settings is split into pages, the window remembers its place, and the commit card opens only from the Author column. There is still no commit, push, stage or diff.

Git 2.15 or newer must already be installed; Cthulhu Git never bundles it. SHA-256 checksums are in `checksums.txt`.

The Linux packages need glibc 2.39 or newer: Ubuntu 24.04, Debian 13, Fedora 40 or later.

- **AppImage**, to try it without installing: `chmod +x cthulhu-git-v0.0.7-x86_64.AppImage`, then run it.
- **Debian and Ubuntu:** `sudo apt install ./cthulhu-git-v0.0.7-x86_64.deb`
- **Fedora:** `sudo dnf install ./cthulhu-git-v0.0.7-x86_64.rpm` (openSUSE Tumbleweed: `sudo zypper install` with the same file)

The Mac app is not signed by Apple yet. The first time, open it from Finder, then go to **System Settings → Privacy & Security** and click **Open Anyway**. From a terminal, `xattr -dr com.apple.quarantine "/Applications/Cthulhu Git.app"` does the same.

## Added

- **Open a folder from the bar.** A folder button on the repository bar and on the Settings bar opens the system dialog. It stays dimmed while a dialog or a repository open is already running. By @don-linux. (#10)
- **Switch the checked-out local branch.** The branch name in the bottom bar opens the local branches. Choosing another one checks it out. Git 2.23 and newer run `git switch --no-guess`, so HEAD stays attached to that branch and a remote of the same name is not turned into a new local branch. Git 2.15 through 2.22 confirm the local ref, then run `git checkout`; a name that starts with `-` is refused. There is no `--force`: a dirty file that would be overwritten, or a branch checked out in another worktree, leaves the repository unchanged. The switch updates the work tree, so smudge filters and the `post-checkout` hook run, as they do in a terminal. By @don-linux. (#10)
- **About.** Settings → About shows the version, the date of the commit it was built from, that commit, the license, the Git version Cthulhu Git found, and links to the repository and its releases. Copy version info puts that block on the clipboard for a bug report. By @don-linux. (#10)

## Changed

- **The commit card opens from Author.** Moving across Branch, Graph, Hash, or Message no longer raises the card. The row highlight stays. By @don-linux. (#9)
- **Settings is a list of pages.** Terminal, History, GitHub Auth, and About sit on the left. The chosen page is a column on the right. Both scroll. The font browser is a modal over that page, and the Terminal page draws one prompt line in the chosen font. By @don-linux.

## Fixed

- **The window keeps its place.** It opens maximized the first time. After that, the saved position, restored size, and whether it was maximized come back. By @don-linux.
- **Opening a repository does not hold the window.** The bars are ready before the history graph. That graph runs on a worker. While it is still running, an empty table says "Opening history…". A finished load with no commits still says "No commits yet." Those lines wrap inside the history column. By @don-linux.
