Cthulhu Git 0.0.3 is the first release of the interface as you use it: a home screen to open a repository, and a Git view that lists that directory. It is also the release that hardens that open path, after a pass of tests written to break it. It is still read-only: no commit, push, stage or diff yet.

**Download Cthulhu Git:** [Mac (Apple Silicon and Intel)](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.3/cthulhu-git-v0.0.3-macos-universal.dmg) · [Windows](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.3/cthulhu-git-v0.0.3-x86_64-pc-windows-msvc.zip) · Linux: [AppImage](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.3/cthulhu-git-v0.0.3-x86_64.AppImage), [.deb](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.3/cthulhu-git-v0.0.3-x86_64.deb), [.rpm](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.3/cthulhu-git-v0.0.3-x86_64.rpm), [.tar.gz](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.3/cthulhu-git-v0.0.3-x86_64-unknown-linux-gnu.tar.gz)

Git 2.15 or newer must already be installed; Cthulhu Git never bundles it. SHA-256 checksums are in `checksums.txt`.

The Linux packages need glibc 2.39 or newer: Ubuntu 24.04, Debian 13, Fedora 40 or later.

- **AppImage**, to try it without installing: `chmod +x cthulhu-git-v0.0.3-x86_64.AppImage`, then run it.
- **Debian and Ubuntu:** `sudo apt install ./cthulhu-git-v0.0.3-x86_64.deb`
- **Fedora:** `sudo dnf install ./cthulhu-git-v0.0.3-x86_64.rpm` (openSUSE Tumbleweed: `sudo zypper install` with the same file)

The Mac app is not signed by Apple yet. The first time, open it from Finder, then go to **System Settings → Privacy & Security** and click **Open Anyway**. From a terminal, `xattr -dr com.apple.quarantine "/Applications/Cthulhu Git.app"` does the same.

## Added

- **Home screen.** **Open repository…** uses the system folder dialog. The ten most recent repositories stay one click away. Any folder inside a repository works; its root is what gets remembered.
- **Git view.** The repository you open is listed here: its name in the top bar, the latest commit in the middle, and the history in a sidebar you can hide. The bottom bar shows the branch and a **Home** button. Up to 1000 commits, newest first, each as a 12-character hash and its summary. By @don-linux. (#3)
- **One dark theme.** Colors come from a palette, so later screens can share the same look. The last repository reopens on the next launch.

## Security

- **Opening a repository no longer runs commands planted in it.** Reading the branch no longer uses `git status`, which refreshed the index and could run clean and process filters from that repository. By @don-linux. (#4)
- **A parent process cannot rewrite the history you see.** Replace refs, shallow files, graft files and Git trace variables inherited from a hook or a shell are ignored.
- **The command shown for a repository owned by someone else is safe to paste.** The `safe.directory` path is quoted, so a space or a newline in the path cannot become a second command.
- **Saving settings cannot follow a planted temporary file** onto a file outside the config folder, and two saves at once cannot publish a torn settings file.

## Fixed

- **Bare repositories open**, and a folder whose name ends in a newline opens as that folder.
- **A settings file saved by Windows Notepad loads.** A UTF-8 BOM, or a recent list set to `null`, no longer rejects the whole file.
- **Finder no longer treats its launch argument as a folder.** An argument that starts with `-`, such as `-psn_…`, is ignored, and the last repository opens instead.
