Cthulhu Git 0.0.9 moves to egui 0.37, shows the recent repositories as cards on Home, and fixes a long list of Git, terminal and network bugs, several of them security issues. There is still no commit, push or stage.

**Download Cthulhu Git:** [Mac (Apple Silicon and Intel)](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.9/cthulhu-git-v0.0.9-macos-universal.dmg) · [Windows](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.9/cthulhu-git-v0.0.9-x86_64-pc-windows-msvc.zip) · Linux: [AppImage](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.9/cthulhu-git-v0.0.9-x86_64.AppImage), [.deb](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.9/cthulhu-git-v0.0.9-x86_64.deb), [.rpm](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.9/cthulhu-git-v0.0.9-x86_64.rpm), [.tar.gz](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.9/cthulhu-git-v0.0.9-x86_64-unknown-linux-gnu.tar.gz)

Git 2.15 or newer must already be installed; Cthulhu Git never bundles it. SHA-256 checksums are in `checksums.txt`.

The Linux packages need glibc 2.39 or newer: Ubuntu 24.04, Debian 13, Fedora 40 or later.

- **AppImage**, to try it without installing: `chmod +x cthulhu-git-v0.0.9-x86_64.AppImage`, then run it.
- **Debian and Ubuntu:** `sudo apt install ./cthulhu-git-v0.0.9-x86_64.deb`
- **Fedora:** `sudo dnf install ./cthulhu-git-v0.0.9-x86_64.rpm` (openSUSE Tumbleweed: `sudo zypper install` with the same file)

The Mac app is not signed by Apple yet. The first time, open it from Finder, then go to **System Settings → Privacy & Security** and click **Open Anyway**. From a terminal, `xattr -dr com.apple.quarantine "/Applications/Cthulhu Git.app"` does the same.

## Added

- **Home shows the recent repositories as cards.** Each card shows the folder name, the path, the current branch, how far it is ahead of or behind its upstream, and the subject and time of the latest commit. The logo, the version and **Settings** sit beside **Open repository…**. By @don-linux.

## Changed

- **The branch and commit sidebars open at their default width once after updating.** egui 0.37 identifies a panel by where it sits in the window as well as by its name, so the widths 0.0.8 saved no longer match. Drag them again and they are remembered as before. By @don-linux. (#20)
- **Interface icons and the logo are drawn from their SVG files** at the size and display scale they are shown at, so they stay sharp on high-DPI screens. By @don-linux. (#20)
- **Text in a script no bundled font covers, such as Chinese, Japanese or Korean, is drawn with the system's fonts** when it has them, instead of boxes. Emoji still come from the bundled monochrome fonts, so they look the same everywhere. By @don-linux. (#20)
- **The terminal always gets `TERM=xterm-256color`.** It used to get `alacritty` when that terminfo entry was installed. Every Linux and macOS system ships `xterm-256color`, so programs see the same terminal everywhere. By @don-linux. (#20)
- **Git is looked for once.** The Git found first serves every open, the recent cards and About. It is looked for again only when it can no longer start, for example after it was moved or uninstalled. By @don-linux. (#20)
- **A lit branch fades in and out, and its glow follows a lane change without a gap.** Clicking a branch tag fades its lane's light and the tag in over a third of a second and fades out the branch lit before; where a lit lane moves to another column, the glow now reaches the edge of the row instead of leaving a dark notch at the bend. The moving light no longer redraws the window while the lit lane is scrolled away or the window is in the background. By @don-linux. (#20)

## Fixed

- **A branch named like a tag, or a branch called `HEAD`, no longer stops the repository from opening.** Branch and tag names are read without Git's `heads/` and `tags/` prefixes, so both lists show the plain name. By @don-linux. (#20)
- **Fetch works with a remote whose name has a `/`, such as `team/origin`.** It reads the remote and the merge ref from the branch's config, and takes the first `merge` value, as Git does. Fetch is offered only when the upstream is a remote-tracking branch; otherwise its hover says why. By @don-linux. (#20)
- **A diff line such as `+price 160000` no longer turns a file into "Submodule update."** Binary and submodule markers are read from each file header only, including both halves of a type change such as a symlink replaced by a file. By @don-linux. (#20)
- **Git 2.16 through 2.35 no longer run a program named `false` on every index read** during a switch, checkout or pull. fsmonitor is turned off with an empty `core.fsmonitor`, which every Git version reads as off. By @don-linux. (#20)
- **A long session no longer keeps every commit and diff it read.** The hover card, the commit sidebar and **View changes** keep at most 256 commits and 256 diffs, and drop the one asked for longest ago. By @don-linux. (#20)
- **Escape, Tab and the arrows reach the shell in the terminal.** Escape reaches vim, Tab completes and the arrows walk the shell history instead of moving focus. Ctrl+Tab and Ctrl+Shift+Tab move focus out of the terminal. By @don-linux. (#20)
- **Color queries get the colors on screen.** OSC 10, 11, 12 and 4 are answered with the colors the terminal paints, from the theme and its ANSI table, so vim and other programs choose light or dark colors correctly. They used to get black unless the program had set the color first. By @don-linux. (#20)
- **Function and cursor keys send what xterm sends.** Shift, Ctrl or Alt with F1 to F4 send `CSI 1;<mod> P` to `S`, and Home and End send `ESC O H` and `ESC O F` in application cursor mode, so less and vim recognize them. By @don-linux. (#20)
- **The terminal opens when a variable in the environment is not valid Unicode.** By @don-linux. (#20)
- **A prompt of several lines shows whole on the Terminal settings page**, up to eight lines. By @don-linux.
- **Importing the token from GitHub CLI gives up after 5 seconds**, even when a program `gh` started keeps its output open. It used to wait, with GitHub Auth showing a spinner, until that program exited. By @don-linux. (#20)
- **A token that failed to save says it is not saved.** A keychain that timed out or was locked said "Still waiting on the keychain". Every failed save now says the token is used until Cthulhu Git closes and is not saved, and a save that lands too late and cannot be undone deletes the entry. By @don-linux. (#20)
- **A token saved to the keychain is always in the system keychain.** With `CTHULHU_KEYRING=sample` set, the app kept it in memory only, so it looked saved and was gone at the next launch. That variable is gone. By @don-linux. (#20)
- **A picture server that stalls is tried again later.** A download that stopped past the time limit after the server had answered was remembered as "no picture" for a day. By @don-linux. (#20)
- **An invalid settings file is reported as left as it is.** The message said the defaults were used "until a setting changes", but nothing is saved over a file that failed to load. By @don-linux. (#20)
- **Icon buttons and branch checkboxes have accessible names.** A screen reader reads the button's tooltip and the branch name instead of a bare "button" or "checkbox". By @don-linux. (#20)
- **The commit hash in the hover card is drawn in the monospace font.** By @don-linux. (#20)
- **On Linux, the zenity folder dialog starts next to the most recent repository**, like the portal dialog, and opens a folder whose name has a `|` or starts or ends with a space. zenity is used only when no desktop portal answers. By @don-linux. (#20)
- **Every package ships the license notices of egui's fonts and of the interface icons.** Hack, Noto Emoji, emoji-icon-font, Ubuntu Light and the Lucide icons are compiled into the app, and their licenses require the notice to travel with them. By @don-linux. (#20)

## Security

- **Git never looks up a helper in the repository folder.** Empty and relative `PATH` entries are removed for every Git command on every platform, so `ssh`, a credential helper or `gpg` cannot be planted in a repository. They used to be removed only on macOS, and only when Homebrew folders were added. By @don-linux. (#20)
- **On Windows, inherited `GIT_*` variables are removed from Git commands whatever their case.** Git for Windows reads `Git_Dir` as `GIT_DIR`, so a mixed-case name could still point Git at another repository. By @don-linux. (#20)
- **The Windows terminal cannot be made to start `C:\Program.exe`.** The PowerShell path is quoted for ConPTY, so the space in `C:\Program Files` no longer makes Windows try a program planted at `C:\Program.exe` first. By @don-linux. (#20)
- **An error message never shows a refused URL.** A redirect to a malformed URL put its user, password and query, which can hold a token, into the message. A refused request now has one fixed message. By @don-linux. (#20)
- **A crafted `Co-authored-by:` line cannot stall the history.** A 1 MiB line took about a minute to parse; co-authors are now read in linear time. By @don-linux. (#20)
- **`settings.json` and the avatar cache are readable only by you on Linux and macOS.** Each save creates the file with mode 0600 instead of following the umask. By @don-linux. (#20)
