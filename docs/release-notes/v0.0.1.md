Cthulhu Git 0.0.1 is the first alpha: a small desktop Git client that finds the Git installed on your machine and shows the repository name, its root folder and the current branch for any folder you point it at. It is read-only for now: no commit, push, stage or diff yet, and there is no folder picker, so the path is typed or pasted.

**Download Cthulhu Git:** [Mac (Apple Silicon and Intel)](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.1/cthulhu-git-v0.0.1-macos-universal.dmg) · [Windows](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.1/cthulhu-git-v0.0.1-x86_64-pc-windows-msvc.zip) · [Linux](https://github.com/don-linux/Cthulhu-Git/releases/download/v0.0.1/cthulhu-git-v0.0.1-x86_64-unknown-linux-gnu.tar.gz)

Git 2.15 or newer must already be installed; Cthulhu Git never bundles it. SHA-256 checksums are in `checksums.txt`.

The Mac app is not signed by Apple yet. The first time, open it from Finder, then go to **System Settings → Privacy & Security** and click **Open Anyway**. From a terminal, `xattr -dr com.apple.quarantine "/Applications/Cthulhu Git.app"` does the same.

## Added

- **Finds Git on its own.** `CTHULHU_GIT` if you set it, then every directory in `PATH`, then the usual install locations on Linux, macOS (Homebrew, Xcode Command Line Tools) and Windows (Git for Windows, Scoop), so it works even when started from the desktop with a minimal `PATH`.
- **Shows where you are.** Repository name, root folder and branch, including a repository with no commits yet and a detached HEAD. Any folder inside a repository works.
- **Never touches your repository.** Git runs without optional locks, pager, prompts or fsmonitor, and variables such as `GIT_DIR` inherited from a hook or shell are ignored.
- **Respects `safe.directory`.** A repository owned by another user shows the exact `git config` command to trust it.
- **Stays responsive.** Every refresh runs in the background.
- **Downloads for three platforms:** a universal Mac app for Apple Silicon and Intel, a portable Windows x86-64 zip and a Linux x86-64 archive.
