Cthulhu Git 0.0.5 draws the commit graph. The history is a table, and each branch you check gets a colored lane that meets the others where the histories join. Author pictures and a commit card sit on that table. Fetch and a fast-forward pull sit next to the current branch; there is still no commit, push, stage or diff.

## Added

- **Commit graph.** The history table has Branch, Graph, Commit Hash, Commit Message and Author. Opening a repository draws only the branch you are on, in the left lane and the first color. Checking another branch adds a lane to the right, in a color tied to its place in the sidebar, until it meets the shared history. Unchecking it removes that lane. A detached HEAD shows that commit and leaves every branch unchecked. By @don-linux. (#6)
- **Commit card.** Resting the pointer on a commit opens a card: avatar, author, mail link, relative and exact date, co-authors, the full message, the branches on that commit, files changed when git prints a short stat, the full hash with Copy, and Open on GitHub when a GitHub remote was found. By @don-linux.
- **Author pictures.** The Author column shows the author's avatar and up to two co-authors from `Co-authored-by` (`+N` for more), then the names. Pictures come from GitHub and Gravatar and are cached; initials stand in when there is none, or when Settings → History turns the pictures off. By @don-linux.
- **GitHub Auth.** Settings → GitHub Auth takes an optional read-only token for private repositories and a higher request limit. It is stored in Keychain, Credential Manager or the Secret Service, never in `settings.json`. It can be imported from GitHub CLI or from `GH_TOKEN` / `GITHUB_TOKEN`. By @don-linux.
- **Fetch and pull.** Next to the current branch, Fetch updates that branch's upstream and Pull fast-forwards the local branch. Both need an upstream that is still tracking. A pull that is not a fast-forward is refused. By @don-linux.

## Changed

- **Branch checkboxes choose the graph.** In 0.0.4 each row had a checkbox and the list still showed HEAD. Marking or unmarking a branch now reloads the graph. A branch that appears after fetch or pull stays unchecked until it is marked. If the checked-out branch is unchecked, the left lane is `main`, then `master`, then `trunk`, then the tip with the newest committer time. By @don-linux. (#6)
- **Column widths.** Drag a divider to resize one history column; double-click it to restore that column. The widths are remembered. When the columns are wider than the panel, the table scrolls sideways. By @don-linux.

## Fixed

- **The terminal can clear its screen.** `clear` and Ctrl+L erase the shell. The shell is given `TERM` and `COLORTERM` for that; the rest of the app is unchanged. By @don-linux.
